Getting Started

You need your own copy of Morrowind, from Steam or GOG. Modern Morrow plays Morrowind's game files, and doesn't come with them. Pick your device:

Windows Steam Deck Linux Android

Downloads

Every file is on the Releases page. Take them from the newest release.

DeviceFile
WindowsModernMorrow-…-Windows-x64.exe, the installer. ModernMorrow-…-Windows-x64.zip has the same files without an installer.
Steam Deck and LinuxModernMorrow-AutoUpdate.sh, which keeps the game up to date by itself. ModernMorrow-…-Linux-x86_64.AppImage is the game alone, to update by hand.
AndroidModernMorrow-…-Android-arm64.apk

Windows

  1. Install Morrowind from Steam or GOG.
  2. Download the installer, ModernMorrow-…-Windows-x64.exe, from the Releases page.
  3. Run it. The builds aren't signed, so Windows SmartScreen may warn you the first time. Choose More info, then Run anyway.
  4. Set up the game data. When the installer finishes, it opens the Modern Morrow Launcher, which offers to run the setup wizard the first time. Choose to use an existing installation, and pick your copy of Morrowind. If it isn't listed, browse to Morrowind.esm in its Data Files folder. Steam keeps Morrowind in C:\Program Files (x86)\Steam\steamapps\common\Morrowind, and GOG Galaxy in C:\Program Files (x86)\GOG Galaxy\Games\Morrowind.
  5. Play. From now on, start the game with the Modern Morrow shortcut in the Start menu.

Rather not install anything? Unpack the zip anywhere, and run openmw-launcher.exe the first time to set up the game data. After that, openmw.exe starts the game.

Steam Deck

The game runs straight on SteamOS, without Proton. The steps are the same on a Steam Machine.

  1. Install Morrowind from your Steam library.
  2. Switch to Desktop Mode. Press the Steam button, choose Power, then Switch to Desktop.
  3. Download Modern Morrow. Make a folder for it. In a web browser, open the Releases page and download one of these into your folder:
    • ModernMorrow-AutoUpdate.sh, to keep the game up to date by itself. Each time it starts, it downloads a newer build if there is one. Without an internet connection, it starts the copy it already has.
    • ModernMorrow-…-Linux-x86_64.AppImage, to update by hand.
  4. Make it executable. In the Dolphin file manager, right-click the file, choose Properties, then Permissions, and tick Allow executing file as program.
  5. Add it to Steam. In Steam, choose Games, then Add a Non-Steam Game to My Library. Choose Browse, set the file type to All Files, and add the file you downloaded. Leave the other options alone.
  6. Start it once in Desktop Mode. Start Modern Morrow from your Steam library. With the update script, this first start needs an internet connection. The setup wizard opens: choose to use an existing installation. It finds Morrowind on the internal drive by itself. If Morrowind is on a microSD card, browse to steamapps/common/Morrowind on the card instead.
  7. Play in Game Mode. Go back to Gaming Mode and start Modern Morrow from your library. From now on, it goes straight into the game.

Start Modern Morrow from Steam rather than by double-clicking it in Dolphin, which refuses to start some AppImages.

Linux

  1. Install Morrowind from Steam or GOG.
  2. Download ModernMorrow-AutoUpdate.sh or ModernMorrow-…-Linux-x86_64.AppImage from the Releases page into a folder of its own.
  3. Make it executable, with chmod +x or your file manager's permissions.
  4. Start it. The first time, the setup wizard opens. Choose to use an existing installation, and pick your copy of Morrowind. After that, the file goes straight into the game.

Android

  1. Install the app. On your phone or tablet, download ModernMorrow-…-Android-arm64.apk from the Releases page and open it.
  2. Start Modern Morrow. It asks for Morrowind's Data Files folder.
  3. Give it the game data, in one of three ways:
    • From the device, such as from Downloads. Tap "Choose folder" and pick Data Files or the folder that holds it, or tap "Choose zip file" and pick a zip of either. The app copies the files in.
    • From a computer. Connect the device over USB, and copy Data Files into Android/data/io.github.durhamg.modernmorrow/files/Morrowind. Then tap "Check again".
    • From the top of the device's storage. Put Data Files in a Morrowind folder there, and tap "Allow access to all files".

Uninstalling the app deletes its folder, with your saves and the game data the first two ways put there. To update, install the new APK over the old one.

Controls

Modern Morrow is made for a gamepad, and every screen works with one. Mouse and keyboard work too, with some rough edges. On Android, a new game starts by showing how the touch controls work.

Coming from OpenMW

Modern Morrow keeps its settings and saves apart from OpenMW's. To bring a game over, use the Load menu, which can import saves from OpenMW. The Save menu can export a save back. You need OpenMW 0.52 or newer.

Coming from the original game

First convert the save with OpenMW's openmw-essimporter tool, and put the result in a character folder in OpenMW's saves folder. Then import it from the Load menu. The converted save keeps your quest progress, but not your journal entries.

Mods and settings

The Modern Morrow Launcher sets up mods and settings. On Windows, it's in the Start menu. On the Steam Deck, set the shortcut's launch options to --launcher for one start, or --wizard to run the setup wizard again.

Where your files are

Settings and saves are in Documents/My Games/Modern Morrow on Windows, and in ~/.config/modern-morrow and ~/.local/share/modern-morrow on Linux and the Steam Deck.

Something wrong?

Report it on the Modern Morrow GitHub. If the Steam Deck's update script isn't working, ModernMorrow-AutoUpdate.log in its folder says what the last check did.

Modern Morrow is a fork of OpenMW. The OpenMW team hasn't reviewed it, so please report its bugs on the Modern Morrow GitHub rather than to OpenMW.
